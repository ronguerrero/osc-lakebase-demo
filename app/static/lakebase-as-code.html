Lakebase as Code (DABs)

Declare a Lakebase project, and optionally an app bound to it, in a bundle. Deploy it, use it, destroy it.

How it works

The bundle below declares a postgres_projects resource (and, on the second tab, an apps resource bound to its database). This app runs the same databricks bundle deploy you would run from a laptop or a CI pipeline.

Your names are passed as bundle variables and each deployment keeps its own state folder, so several people can deploy the same bundle at once. You get CAN_MANAGE on what you deploy; use Destroy to remove it.

Lowercase letters, digits and dashes; starts with a letter.

2-30 characters; becomes part of the app URL.
